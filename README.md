# 🧮 Calculator-C

A simple, fast, and efficient command-line calculator written in C. This project is part of my foundational software engineering roadmap, focusing on core programming concepts like operators, functions, and control flow in C.

## 🚀 Features
* **Basic Arithmetic Operations:** Supports Addition (+), Subtraction (-), Multiplication (*), and Division (/).
* **Error Handling:** Built-in checks for mathematical errors, such as preventing division by zero.
* **Interactive CLI:** Easy-to-use command-line interface that prompts the user for inputs and operations.
* **Lightweight:** Minimal resource footprint, compiled directly from C source code.

## 🛠️ Built With
* **Language:** C
* **Compiler:** GCC (GNU Compiler Collection)
* **Environment:** Linux (Ubuntu/Kali)

## ⚙️ Getting Started

### Prerequisites
Make sure you have `gcc` installed on your Linux system. If not, you can install it using:
```bash
sudo apt update
sudo apt install build-essential
Installation & Compilation
Clone this repository:

Bash
git clone [https://github.com/BLack-Barth/calculator-c.git](https://github.com/BLack-Barth/calculator-c.git)
Navigate to the directory:

Bash
cd calculator-c
Compile the C source code:

Bash
gcc calculator.c -o calculator
🎮 Usage
Run the compiled executable from your terminal:

Bash
./calculator
Follow the on-screen prompts to enter your numbers and choose the operation you want to perform.
